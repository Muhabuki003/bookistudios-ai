# Introduction

bookistudios AI is a framework for building and operating agent systems. It combines a runtime harness for composing agents with memory, tools, skills, sandboxes, and subagents, with an application layer that turns those capabilities into a usable product experience.

This section builds the mental model you need before looking at implementation details. If you are new to bookistudios AI, start here.

<Callout type="info" emoji="🦌">
  You do not need to read everything before you start. Skim this section, then jump
  to the Harness or App docs depending on what you are building.
</Callout>

## What you will learn

- **Why bookistudios AI** explains the motivation behind the project and why it is shaped as a harness rather than just a framework or an app.
- **Core Concepts** introduces the concepts that appear across the rest of the documentation.
- **Harness vs App** explains the relationship between the runtime layer and the application layer, and how to choose the right entry point.
