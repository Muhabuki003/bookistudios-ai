# 简介

bookistudios AI 是一个用于构建和运行 Agent 系统的框架。它提供了一个运行时 Harness，可以将 Agent 与记忆、工具、技能、沙箱和子 Agent 组合在一起；同时还提供了一个应用层，将这些能力转化为可用的产品体验。

本章节帮助你在深入实现细节之前建立正确的思维模型。如果你是 bookistudios AI 新手，请从这里开始。

<Callout type="info" emoji="🦌">
  不必在开始前读完所有内容。浏览本章节后，根据你要构建的内容直接跳到 Harness 或应用文档。
</Callout>
